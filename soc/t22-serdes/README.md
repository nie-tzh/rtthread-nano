# T22 SerDes SoC层

本目录描述T22解串器和加串器共享的系统集成平台。当前提供公共启动程序、默认XIP内存布局、公共地址、系统时钟、T22 MMIO CSR受保护写和外设复位，并将T22 SerDes绑定到E902 CPU；后续资源描述按具体芯片在编译期选择。

单一控制器的寄存器操作属于`drivers/`，板卡启用的设备实例和引脚用途属于`boards/`。SoC层不复制驱动流程，也不保存板级连接策略。

Board默认复用本目录的启动程序和链接脚本。只有启动介质或内存布局确实不同的板卡，才在自身配置中覆盖`STARTUP_SOURCE`和`LINKER_SCRIPT`。

当前为验证早期串口输出，暂时保留UART2 TX的最小引脚初始化接口；它不作为完整pinctrl设计继续扩展。建立pinctrl子系统时，引脚能力、MFP编码和ECO处理迁入对应驱动，Board只保留引脚状态选择。
